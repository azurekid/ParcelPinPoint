API Documentation

Available Endpoints

GET /api/locations

Retrieve locations with optional filters

Query Parameters:
  • postalCode - Filter by postal code (e.g., 1012JM)
  • service - Filter by service (PostNL, DHL, DPD, GLS, UPS)
  • type - Filter by type (pickup, both)
  • limit - Limit number of results
Example: GET /api/locations?postalCode=1012JM&service=PostNL&limit=5

GET /api/services

Get list of available delivery services

Example: GET /api/services

GET /api/locations/:id

Get details of a specific location by ID

Example: GET /api/locations/1
